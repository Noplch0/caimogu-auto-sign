# 踩蘑菇每日签到扩展

这是一个不依赖 Node、Python 或外部服务的 Chrome Manifest V3 扩展。它只通过当前 Chrome 页面会话访问踩蘑菇，不读取、导出或保存 Cookie、密码和令牌。

## 安装

1. 确认 Chrome 已登录 `https://www.caimogu.cc`。
2. 打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录 `D:\projects\caimogu-sign`。
4. 安装时扩展会执行一次当天签到检查；如果今天还没有签到，会完成一次真实签到。
5. 建议把“踩蘑菇每日签到”固定到工具栏。点击图标可手动检查当天状态。

## 执行规则

- Chrome 每次启动时，如果当天还没有成功记录，会立即补签。
- Chrome 持续运行时，每天北京时间 09:00 执行。
- 网络超时、429 或 5xx 会在 30 分钟后重试，每天最多 3 次。
- 成功或已经签到只更新工具栏徽标；登录失效、网站结构变化或最终失败才弹出通知。
- 自动流程会打开一个非活动签到页，完成检查后关闭自己创建的页签。

徽标含义：绿色 `✓` 表示当天已完成，红色 `!` 表示失败，橙色 `…` 表示正在处理。

## 验证

安装后可在踩蘑菇的签到页确认“今日已签到”、影响力和连续签到天数。当天再次点击扩展图标时，扩展会识别为已签到，不会重复提交。

扩展只在 `chrome.storage.local` 保存最后一次结果、当天成功日期和重试次数；不会保存登录凭据。
