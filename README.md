# 踩蘑菇每日签到扩展

一个不依赖 Node.js、Python 或外部服务的 Chrome Manifest V3 扩展。它复用当前 Chrome 中的踩蘑菇登录会话完成每日签到，不读取、导出或保存 Cookie、密码和令牌。

## 功能

- Chrome 启动时，如果当天尚未签到，会自动补签。
- Chrome 持续运行时，每天北京时间 09:00 自动签到。
- 自动识别“今日已签到”，避免重复提交。
- 网络超时、429 或 5xx 会在 30 分钟后重试，每天最多重试 3 次。
- 登录失效、网站结构变化或最终失败时弹出通知；成功时只更新工具栏徽标。

## 安装

1. 从 GitHub 下载 ZIP，或使用 Git 克隆本项目，然后将压缩包解压到任意目录。
2. 在 Chrome 中登录 [踩蘑菇](https://www.caimogu.cc)。
3. 打开 `chrome://extensions`，开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择刚才解压后的项目目录。正确的目录中应直接看到 `manifest.json`、`background.js` 和 `README.md`。
5. 建议将“踩蘑菇每日签到”固定到 Chrome 工具栏。点击扩展图标可以手动检查当天状态。

安装或重新加载扩展后，它会执行一次当天签到检查；如果今天还没有签到，会完成一次真实签到。

## 运行与状态

自动流程会在后台打开一个非活动的签到页，完成检查后关闭自己创建的页签。扩展徽标含义如下：

- 绿色 `✓`：当天已完成
- 红色 `!`：签到失败或需要重新登录
- 橙色 `…`：正在处理

当天再次运行时，如果页面已经显示“今日已签到”，扩展不会重复发送签到请求。

## 验证签到

打开踩蘑菇的每日签到页面，确认页面显示“今日已签到”，并检查影响力和连续签到天数。也可以点击扩展图标进行一次手动检查。

## 隐私与权限

扩展只申请 `alarms`、`notifications`、`scripting`、`storage` 和 `tabs` 权限，以及踩蘑菇官网的访问权限。`chrome.storage.local` 只保存最后一次结果、当天成功日期和重试次数，不保存登录凭据。

## 常见问题

- **徽标显示红色 `!`**：打开踩蘑菇官网确认登录状态，然后重新登录并点击扩展图标重试。
- **扩展更新后没有生效**：在 `chrome://extensions` 中点击该扩展的刷新按钮。
- **当天 Chrome 一直没有启动**：扩展无法为已经过去的日期补签；下次启动时只会处理当天的签到。
